# Матрица тестовых сценариев

Лабораторная работа 2, вариант 2 «Служба доставки». Матрица составлена до реализации бизнес-логики.

По умолчанию: Standard, вес 1 кг, расстояние 5 км, без хрупкости и страховки. Денежные значения приведены в рублях. Базовый тариф умножается на коэффициент типа доставки, затем прибавляется весовая надбавка, учитывается хрупкость, добавляется страховка и применяется предел 50 000 руб. Округление методичкой не предусмотрено.
