# Разработка по TDD

Для каждого блока правил сначала написаны тесты. Провал подтверждён настоящим запуском xUnit, а не ошибкой компиляции. Только после этапа Red добавлена реализация и выполнен этап Green. После реализации всех правил выполнен Refactor с повторным успешным запуском тестов.

| Этап | Всего | Успешно | Провалено | Изменение |
| --- | ---: | ---: | ---: | --- |
| Подготовка | 1 | 1 | 0 | Решение, два проекта, пакеты, пустой шаблонный тест, матрица сценариев |
| 1 Red | 14 | 0 | 14 | Тесты валидации и минимального тарифа; API содержит заглушку |
| 1 Green | 14 | 14 | 0 | Проверки входных данных и минимальный тариф 200 руб. |
| 2 Red | 49 | 19 | 30 | Новые тесты тарифных границ, веса, типа и хрупкости |
| 2 Green | 49 | 49 | 0 | Реализованы тарифы, коэффициенты и хрупкость |
| 3 Red | 64 | 56 | 8 | Новые тесты страховки и порядка надбавок |
| 3 Green | 64 | 64 | 0 | Условная страховка 2%, минимум 100 руб. |
| 4 Red | 77 | 70 | 7 | Тесты ограничения, максимальных входов, точности и повторяемости |
| 4 Green | 77 | 77 | 0 | Ограничение окончательной цены 50 000 руб. |
| Refactor | 77 | 77 | 0 | Выделены валидация, расчёт базового тарифа, веса и коэффициента |

Каждый этап сохранён отдельным коммитом. Точные результаты и команды находятся в `evidence/tdd-runs.json`, полные журналы xUnit — в `evidence/tdd/`. Первоначальный пустой тест удалён до разработки бизнес-логики.

Для промежуточного анализа после реализации тарифов отдельно запущена группа `ValidationTests`: Line Coverage 82%, Branch Coverage 75%. Этот запуск проверяет только валидацию, поэтому тарифные ветви остаются непокрытыми. В финальном запуске включены все четыре класса тестов, добавлены страховка и ограничение цены, выполнен рефакторинг: Line Coverage 100% (57/57), Branch Coverage 100% (32/32). Метрики относятся к сборке `Lab2.Core`, тестовая сборка не учитывается.
